# Товарный отчет (Telegram)

Витрина «план / факт / остаток» по сети магазинов и Telegram-бот, который отдает отчет по запросу.

## Как это работает

- `app.py` - раз в 24 часа (и сразу при старте) собирает витрину по месяцам, магазинам, бит литерам и категориям и перезаписывает `report.xlsx` на Google Drive. Данные (план, продажи по товарам, остатки) читает с Drive.
- `bot.py` - Telegram-бот (long polling). Команды:
  - `/updated` - дата, по которую обновлены данные;
  - `/report` - присылает файл `report.xlsx`.
- `drive_client.py` - работа с Google Drive API.

## Поля отчета

месяц, магазин, бит литера, категория, план, факт MTD, выполнение плана, плана осталось, остаток шт, средняя цена продажи с учетом скидки, сколько шт продать осталось, возможность выполнить план (по остатку), даты факта и остатка.

## Запуск

Нужны `.env` (токен бота, id файлов на Drive) и папка `creds/` с OAuth-файлами Google (в репозитории их нет).

```
docker compose up -d --build   # сервисы app и bot
```

Без Docker: `pip install -r requirements.txt`, затем `python app.py --schedule` и `python bot.py`.
